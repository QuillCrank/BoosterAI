# Successful generalized experiences

Each public experience contains working generic code, a sanitized verification summary, code/evidence hashes, nested category paths, tags and preserved revisions. Failures and code-free anecdotes are not public entries. Search before rewriting; reverify adaptations in the actual target. Archived files and operations do not get transaction logs.

`archive.schema.json` defines the CodeMeta/SoftwareSourceCode-inspired profile. `index.json` is generated deterministically from current metadata and, when present, the separate relationship registry; the bundled validator supports the profile's documented subset, not all JSON Schema features. The sync reader accepts v1, v2 and v3 indices. On recurrence, improve the existing experience without discarding revisions. See `../references/solution-archive.md` for commands, publication scope, rights and safeguards. No measured token/time saving is implied by archive membership.
